# Публічні сторінки гри «Козацька Звитяга»

Тут лежать лише сторінки, які мають бути відкриті всім:

- `Jarvis/index.html`: сторінка гри.
- `Jarvis/privacy/index.html`: політика приватності.
- `Jarvis/delete-account/index.html`: видалення облікового запису.

Адреси цих сторінок вписано в Google Play і в саму гру, тому назви тек міняти не можна.
